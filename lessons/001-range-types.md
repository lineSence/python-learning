## Диагностика (стартовые вопросы)

| Вопрос | Ответ ученика | Разбор |
| --- | --- | --- |
| Переменная, функция | Хранилище значения; блок кода, выполняющий функцию | Функция: принимает входные данные и возвращает результат, вызывается многократно |
| `"5"` и `5` | Текст и число | Верно |
| `for i in range(3): print(i*2)` | «i от 0 до 3», не уверен | Ошибка: `range(3)` = 0, 1, 2. Вывод `0 2 4` |
| Терминал | cmd, PowerShell, bash — синтаксис забывается | Норма, решается практикой |
| Git | Контроль версий, знаю мало | Верно в общих чертах |
| SQL, API | SQL — язык баз данных; API описать не смог, хотя пользуется | См. ниже |
| Что происходит при открытии сайта | Сетевой путь, DNS, CDN, хостинг | Хорошо. Не хватало: DNS — отдельный запрос до соединения; HTTP-запрос и ответ, затем догрузка CSS, JS и картинок |

## API — разобранный пример

API — договорённость, как одна программа просит что-то у другой. Пример из бота:

```
POST https://api.telegram.org/bot<ТОКЕН>/sendMessage
{"chat_id": 123456789, "text": "Печать завершена"}
```
Ответ: `{"ok": true, "result": {"message_id": 42}}`

Проверка: верно описал Moonraker (бот спрашивает, Moonraker отвечает). Уточнение: API отдаёт данные для программы, не обязательно JSON (может быть картинка с камеры).

## Новое: `range`

```python
for i in range(3):   # 0, 1, 2 — конец не входит
    print(i * 2)
range(1, 4)          # 1, 2, 3
range(0, 10, 2)      # 0, 2, 4, 6, 8
```

## Новое

| Функция | Пример |
| --- | --- |
| `int()` | `int("25")` → `25` |
| `float()` | `float("3.5")` → `3.5` |
| `str()` | `str(25)` → `"25"` |
| `type()` | `type("25")` → `<class 'str'>` |

```python
age = int(input("Возраст: "))   # изнутри наружу: сначала input, потом int
```

Типичные ошибки: `int("тридцать")`, `int("3.5")`, `float("3,5")` → `ValueError`. Запятая — частая проблема данных из 1С и Excel.

### Разбор программы «цена × количество»

Ответ ученика: `Price=input (”Цена=” “) n=input (” Колличество=””) print=float(price*n)`

| Ошибка | Почему |
| --- | --- |
| `Price` и `price` | Регистр важен |
| `” “` | Только прямые кавычки |
| `"Цена=" "` | Лишняя кавычка |
| `print=` | Присваивание вместо вызова |
| `float(price*n)` | Преобразовывать до умножения |

Эталон:
```python
price = float(input("Цена: "))
n = int(input("Количество: "))
print(price * n)
```

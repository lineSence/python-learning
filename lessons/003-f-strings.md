## Новое

```python
cost = 300.0
print(f"Стоимость доставки: {cost} руб.")      # 300.0
print(f"Стоимость доставки: {cost:.2f} руб.")  # 300.00
print(f"Итого: {weight * price_per_kg:.2f} руб.")
```

- `f` перед кавычками — в строке есть вставки `{}`
- `:.2f` — 2 знака после точки
- Типичная ошибка: забыть `f` — выведутся сами скобки

### Разбор задачи 4

| Ошибка | Почему |
| --- | --- |
| `+ sum` | Скидка прибавлена: 1500 и 15 → 1725 вместо 1275. Логическая ошибка — проверять результат на контрольных числах |
| Нет переменной скидки в рублях | Строка «Скидка 15%: 225.00 руб.» требует суммы скидки |
| `sum = ...` | `sum` — встроенная функция Python, имя её затирает (как `print =`) |
| `float(sum/100*dis+sum)` | Лишний `float`: числа уже дробные |
| Нет `:.2f`, формат вывода не по условию | `1500.0` вместо `1500.00`, `=` вместо `: ` |
| `dis` | Неясное имя → `discount_percent` |

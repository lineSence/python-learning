## Новое

```python
cost = 300.0
print(f"Стоимость доставки: {cost} руб.")      # 300.0
print(f"Стоимость доставки: {cost:.2f} руб.")  # 300.00
print(f"Итого: {weight * price_per_kg:.2f} руб.")
```

- `f` перед кавычками — в строке есть вставки `{}`
- `:.2f` — 2 знака после точки
- Типичная ошибка: забыть `f` — выведутся сами скобки

# python-learning

Мой путь изучения Python — с нуля до уровня джуна в бэкенде и автоматизации.

Обучение построено на [10 принципах Розеншайна](docs/method.md): маленькие шаги, разобранные примеры, практика с проверкой и регулярное повторение. Записи ведутся по адаптированной схеме [Self-Evolving Knowledge](https://habr.com/ru/articles/1041612/): репозиторий хранит всё, что нужно, чтобы любой ИИ-наставник продолжил занятие с нужного места, не опираясь на память чата.

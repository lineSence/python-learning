# Inbox — свежие ошибки и неожиданности

Черновики. Формат: дата, что ожидал, что на самом деле, вывод.
Если ошибка повторяется или подтверждена — переносится в статус навыка `шаткий` в `skills.md` и в очередь повторения, а здесь удаляется. Лимит — 20 записей.

- **2026-10-04 · range** — ожидал, что `range(3)` даёт 0–3. На деле 0, 1, 2. → Граница stop не входит.
- **2026-10-04 · строки** — `"3" * 3` → ответил `33`. На деле `333`. → Умножение строки на n повторяет её n раз.
- **2026-10-04 · порядок** — `float(price*n)`: сначала умножение строк, ошибка. → Преобразовывать до операции.
- **2026-10-04 · print** — написал `print = float(...)`. → Это присваивание, а не вызов; функция print затирается.
- **2026-10-04 · кавычки** — изогнутые `“ ”` вместо прямых. → Python понимает только `"` и `'`. Писать код в редакторе, а не в Word или на телефоне.
- **2026-10-04 · регистр** — `Price` и `price` в одной программе. → Это разные имена.
- **2026-10-04 · пустая строка** — `input("Вес=""")` сработал случайно: соседние строки склеиваются. → Не ставить лишние кавычки.
- **2026-10-04 · f-строка** — `"Итог: {5 + 5}"` ответил `10`. На деле без `f` выводятся сами скобки. → Сначала смотреть на букву перед кавычками.
- **2026-10-04 · сборка программы** — не смог собрать «ввод → вычисление → вывод в f-строке» без заготовки. → Нужны опоры и разбивка на шаги.
- **2026-10-04 · запуск** — решения присылались без запуска. → Каждый ответ проверять запуском (CORE-003).
